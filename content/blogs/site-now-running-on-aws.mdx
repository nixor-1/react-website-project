I have successfully set my website up to run on an AWS EC2 server with Apache HTTP Server. The website is currently running on a free tier on which I have 100 dollars worth of credit. For a while, it only ran on Vercel, which does not grant as much power over the hardware and software as I'd like.

The following steps were involved in making this happen:
